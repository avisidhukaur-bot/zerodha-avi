Jaise aapne browser se PWA install karne ko kaha hai:

1. Web App Manifest (manifest.json):
   - Standalone display mode set karenge jisse browser ki URL bar gayab ho jayegi aur full native app jaisa feel aayega.
   - Dedicated App Icon & Dark Theme set hoga.

2. Service Worker (sw.js):
   - UI assets (CSS/JS) ko cache karega taaki 0 seconds me page load ho.
   - Network drop hone par background auto-reconnect handle karega.

3. 1-Click "Add to Home Screen":
   - Phone par website open karte hi "Install Zerodha OS" ka prompt aayega. Click karte hi mobile home screen par app icon ban jayega.
