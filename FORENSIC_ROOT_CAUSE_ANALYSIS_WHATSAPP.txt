2️⃣ *WHY ORPHAN HEDGE WAS LEFT OPEN AT 15:02 IST? (The Real Bug)*

  15:02 par `24000 CE` ka price benchmark line (₹114.00) ke upar ₹119.55 nikal gaya, toh system ne use exit kar diya (`Buy 130 @ 119.30`). Lekin uska hedge `24500 CE` Zerodha terminal par open reh gaya jise 15:04 par manually bechna pada.

• *Root Cause / Bug in Code*:
  `os_engine.py` (lines 789–796) me 3 PM exit ka code is tarah likha tha:
  `bm.close_strike(s_id, close_hedge=False)`
  `bm.close_strike(h_id, close_hedge=False)`

  *Isme 2 galtiyan thi*:
  1. `close_strike` ko `close_hedge=False` pass karke hedge close karne se mana kar diya gaya.
  2. Uske baad jab code ne alag se hedge ID `h_id` ko close karne ki koshish ki, toh `block_manager.py` ne use reject kar diya kyunki rule hai: *"close_strike sirf SELL leg par chalta hai, Hedge uske sath hi close hota hai."*
  3. Reject hone ke baad bhi DB me hedge ko `CLOSED` mark kar diya gaya bina broker par beche!
  4. *Nateeja*: Database me close dikha raha tha, lekin real broker terminal par `24500 CE` open reh gaya tha.
